# butterfly-bbox

Проект по поиску бабочек на фотографиях и выделению их ограничивающими рамками. Собираем проверенную краудсорсинговую разметку и сравниваем готовые модели, чтобы выбрать наиболее точное решение и понять его ограничения.

- [Задание проекта](docs/final_project_2026.md)
- [Задачи на реализацию](https://github.com/orgs/crowd13/projects/3/views/1)
- [How to contribute](CONTRIBUTING.md)

## Планируемая структура проекта

```text
butterfly-bbox/
├── data/                  # сбор и подготовка фотографий
├── crowd/                 # проекты в tasks.yandex.ru
│   ├── bbox/              # первичная разметка
│   └── review/            # независимая проверка
├── golden_set/            # исправления и итоговая проверенная разметка
├── models/                # запуск моделей, эксперименты и сравнение
├── submission/            # подготовка и отправка в Контест
├── presentation/          # материалы защиты
└── docs/                  # задание и документация проекта
```
