## Передача в review

Берите задания из `review.json`. Поле `solution` содержит `status` и `boxes`;
координаты `left`, `top`, `width`, `height` нормализованы относительно кадра
с учётом EXIF-ориентации. Сохраняйте `answer_id` для связи с исходным ответом,
`photo_id`, `image_url`, `width`, `height` и `worker_id`.
**Автор bbox (`worker_id`) не должен проверять собственный ответ.**
