# Картинки для инструкции

Шесть примеров из одобренного учебного набора. Рамки нанесены в JPEG по
координатам `fixtures/gold/gold.json`; экзамен и контроли здесь не используются.
Платформа удаляет SVG из инструкции, поэтому нужны обычные изображения.

`manifest.json` связывает фото, подписи, хеши ответов и публичные ссылки.
Ссылки закреплены за коммитом GitHub, чтобы изображения не менялись при обновлении ветки.

После изменения учебных рамок:

1. Запустите `python3 -m crowd.bbox.fixtures.build_instruction_examples`.
2. Проверьте JPG, сохраните и отправьте изображения в репозиторий.
3. Замените коммит в `base_url` файла `manifest.json` на коммит с новыми картинками.
4. Проверьте публичные ссылки и обновите инструкцию проекта.

Генератор не меняет gold. Устаревшие рамки обнаруживаются при сборке интерфейса.
Изменение инструкции не отправляет проект на модерацию и не открывает пулы.
