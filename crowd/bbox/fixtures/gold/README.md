# Эталоны bbox

**Команда одобрила все 110 эталонов:** 10 учебных, 10 экзаменационных и
90 контрольных. На 86 фотографиях отмечены 89 бабочек; на 24 — отсутствие
целевых объектов. Взрослые мотыльки и моли включены в разметку.

Подтверждение записано по сообщению пользователя «Команда все подтвердила,
все ок». В каждой записи заполнено `team_approval`, `review_required: false`.
Время в подтверждении — время его фиксации. Источник исходной разметки ИИ
сохранён отдельно; рамки при фиксации одобрения не менялись.
Это эталоны для bbox, а не итоговая разметка рабочих 400 фотографий.

## Просмотр

Из корня репозитория:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/crowd/bbox/fixtures/gold/index.html`.
Галерея показывает рамки, пояснения и ссылки на источники.
После изменения разметки сбросьте одобрение соответствующего кадра,
обсудите изменения с командой и запишите новое подтверждение.
Пересборка галереи: `python3 -m crowd.bbox.fixtures.build_preview`.

## Файлы

- `gold.json` — одобренный банк: рамки, пояснения, сценарии и подтверждения.
- `index.html` — галерея для обсуждения командой.
- `images/` — оригиналы 110 изображений.
- `practice.csv`, `exam.csv`, `controls.csv` — списки эталонов с метаданными.
- `working_manifest.csv` — отдельные 400 рабочих фотографий, без разметки.
- `report.json`, `image_checks.json` — состав банка, подтверждение и проверки.
- `excluded_candidates.json` — причины замены неподходящих кадров.

Формат банка — в [описании эталонов](../README.md). Координаты `left`, `top`,
`width`, `height` нормализованы в [0, 1]. Ссылки на источники, лицензии CC0
и происхождение исходного черновика сохранены в `gold.json`.

## Проверка и запуск

```bash
python3 -m crowd.bbox.project check \
  --manifest crowd/bbox/fixtures/gold/working_manifest.csv \
  --fixtures crowd/bbox/fixtures/gold/gold.json
```

Готовность gold не означает готовность платной выдачи. Дальше следуйте
[инструкции запуска](../../README.md): новый снимок с одобренным банком,
свежий `preflight`, проверка интерфейса и фактической комиссии, `ready`.
Существующие снимки в `runs/` и ресурсы платформы автоматически не обновляются.
