# Черновик эталонов bbox

Подготовлены **110 фотографий с разметкой ИИ**: 10 учебных, 10 экзаменационных
и 90 контрольных. На 77 фотографиях отмечены 80 бабочек; на 33 — отсутствие
целевых объектов. Для каждого кадра записаны сценарии и пояснение.

**Это полный черновик для проверки, а не подтверждённые эталоны.**
`independent_reviews` оставлены пустыми, `review_required: true`.
Платные задания не создавались. Рабочие 400 фотографий здесь не размечаются.

## Просмотр

Из корня репозитория запустите:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/crowd/bbox/fixtures/gold-draft/index.html`.
Галерея показывает рамки и пояснения. Ссылка «Исправить черновик» открывает
редактор с текущим ответом; после исправления нажмите «Скачать ответ JSON».
Редактор использует локальную копию оригинала. Сохранение скачивает отдельный
файл: исходный банк автоматически не меняется.

Для **независимой разметки** используйте `blind.html`: там только ссылки на
пустые редакторы, без ответов и пояснений ИИ. Два участника должны сохранить
собственные ответы отдельно, прежде чем смотреть черновик или ответы друг друга.

## Состав и проверки

В каждом наборе представлены обычные и мелкие бабочки, несколько объектов,
перекрытие, обрезание кадром, похожие насекомые и отсутствие бабочек.
Сценарии могут сочетаться на одном изображении.

Исходную выборку получили из остатка `data/manifest.csv` с seed=42.
После визуального просмотра заменили 10 неподходящих кадров на 10 новых CC0
с iNaturalist и перераспределили часть изображений между наборами.
Причины замен сохранены в `excluded_candidates.json`, метаданные дополнительных
источников — в `provenance/additional_sources.json`. Итоговый состав зафиксирован
в `gold_draft.json`; `draft_provenance` сохраняет происхождение каждой записи.

Проверены формат всех ответов, границы рамок, размеры с учётом EXIF,
покрытие сценариев и отсутствие пересечений по ID фотографии, URL и наблюдению.
Для всех 510 фотографий (рабочие 400 + эталоны 110) нет совпадений хешей
декодированных пикселей. Все 110 черновиков повторно просмотрены с наложенными
рамками. Это проверка ИИ; она не заменяет независимую человеческую разметку
и проверку визуально похожих кадров между наборами.

## Файлы

- `gold_draft.json` — полный черновик банка в формате bbox; координаты `left`, `top`, `width`, `height` нормализованы в [0, 1].
- `working_manifest.csv` — зафиксированные 400 рабочих фотографий.
- `practice.csv`, `exam.csv`, `controls.csv` — актуальные списки эталонов с метаданными.
- `index.html`, `ai-review/` — просмотр и исправление черновика.
- `blind.html`, `preview/` — независимая разметка без подсказок.
- `images/` — оригиналы ровно 110 изображений из банка, без изменения пикселей.
- `report.json`, `image_checks.json` — результаты проверок и оставшиеся условия запуска.
- `provenance/` — сохранённые сведения iNaturalist о дополнительных CC0-источниках.

## До запуска

1. Два участника независимо размечают все 110 кадров, проверяют принадлежность
   объектов, границы рамок, сценарии, пояснения и похожие кадры между наборами.
2. Согласуют расхождения. В копию `gold_draft.json` добавляют реальные
   `independent_reviews`, исправляют `solution` и заполняют `resolution` при
   расхождениях. Формат — в [fixtures/README.md](../../fixtures/README.md).
   Непригодные эталоны заменяют с повторной проверкой покрытия сценариев и дублей.
3. Сохраняют подтверждённый банк как `gold.json`, обновляют происхождение разметки
   и признаки проверки, затем выполняют:

```bash
python3 -m crowd.bbox.project check \
  --manifest crowd/bbox/fixtures/gold-draft/working_manifest.csv \
  --fixtures crowd/bbox/fixtures/gold-draft/gold.json
```

Дальше — [инструкция запуска](../../README.md): подготовка, свежий `preflight`,
проверка интерфейса на платформе и активация. Текущий `gold_draft.json` намеренно
не проходит `check`: отсутствуют две независимые человеческие разметки.

Данные и черновая разметка в этом каталоге хранятся в Git. Рабочее состояние
платформы, ответы исполнителей и временные файлы сохраняйте отдельно в `runs/`.
