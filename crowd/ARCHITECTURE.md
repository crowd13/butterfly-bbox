# Архитектура краудсорсинговой разметки

Bbox реализован; review и сборка golden set пока описаны как план.
Текущая задача — только [bbox](bbox/ARCHITECTURE.md). Проект review и сборка
golden set реализуются отдельно. Требования: [задание проекта](../docs/final_project_2026.md).

## Цель и границы

Получить максимально качественную проверенную разметку всех фотографий
зафиксированного набора при общем лимите **850 ₽**, включая комиссию,
экзамены, контрольные задания, перекрытие и исправления.

Процесс:

```text
Зафиксированный набор → bbox → два независимых review каждого ответа
                                   ↓
                     принять / исправить / разобрать вручную
                                   ↓
                 независимая проверка исправленной версии
                                   ↓
                  финальная проверка командой → golden set
```

Результат bbox — первичные ответы, а не эталон. Сравнение моделей выполняется
в дальнейшем по golden set всего зафиксированного набора.

## Размер и состав набора

Выбран объём **400 фотографий**. Приоритет — качество проверки и достаточный
резерв на исправления. Увеличение до 503 при тех же параметрах оставляет
только 31 ₽ свободного резерва после выделения дополнительного резерва review.

На момент планирования `data/manifest.csv` содержит 593 фотографии:
429 `butterfly`, 106 `lookalike`, 58 `unrelated`. Из 429 фотографий бабочек
61 отмечена как сложная. План отбора:

| Группа | Количество |
| --- | ---: |
| Обычные фотографии бабочек | 219 |
| Все имеющиеся сложные фотографии бабочек | 61 |
| Похожие объекты: моль, другие насекомые, незрелые стадии | 80 |
| Остальной фон: растения и животные | 40 |
| Всего | 400 |

Отбор внутри групп воспроизводим, с фиксированным seed и проверкой разнообразия
авторов и видов. Существующий manifest не перезаписывается: новый список
фиксируется отдельно до платного запуска. Метки сборщика не являются эталоном
и не передаются исполнителям как подсказка. Подтверждённое наличие объектов
определяется после bbox и review. Все отобранные изображения проходят оба этапа.

## Единые правила рамок

- Отдельная прямоугольная рамка для каждой взрослой бабочки.
- Плотно охватываем видимые крылья, тело, лапки и усики.
- При перекрытии или обрезании краем кадра скрытые части не достраиваем.
- Моль, другие насекомые, гусеницы, куколки и тени не размечаем.
- Неоднозначный объект направляем на разбор.
- Ошибку загрузки никогда не превращаем в ответ «бабочек нет».

Координаты нормализованы относительно полного изображения с учётом
EXIF-ориентации: `left`, `top`, `width`, `height` в диапазоне [0, 1].
Инструкция, интерфейсы, эталоны и последующая оценка моделей используют
одни и те же правила.

## Bbox

Один исполнитель рисует рамки; базовое перекрытие — 1. Страница содержит
четыре рабочих изображения и одно скрытое контрольное за 2,50 ₽. Практика встроена
в шаблон; экзамен из 10 изображений за 1 ₽ проверяет рисование. Python оценивает
координаты по локальным эталонам и назначает допуск.

После экзамена используем два рабочих пула: пилот на 40 фотографий и основной
на остальные 360. Пилот проверяют полностью до создания основного пула.
Во время основной выдачи команда регулярно запускает проверку контролей;
при невозможности следить за качеством приостанавливает выдачу. Дополнительная
разметка до 60 изображений — резерв, а не обязательный расход. Подготовка отдельного
банка эталонов, критерии успешного пилота и механика API описаны
в [архитектуре bbox](bbox/ARCHITECTURE.md).

## Review — отдельная будущая задача

Каждый первичный ответ проверяют два других исполнителя. Ревьюер видит весь
кадр, может скрыть рамки и отдельно проверяет:

1. Все ли бабочки найдены.
2. Нет ли лишних объектов и дублирующих рамок.
3. Точно ли проведены границы.

Пустая разметка тоже проверяется на всём кадре. Есть ответы «не уверен»
и «ошибка загрузки». На странице пять рабочих проверок и одна контрольная,
перекрытие — 2. Отдельные обучение, экзамен и навык; начальный порог экзамена
— 90%, с проверкой его пригодности на пилоте. Эталоны включают правильные
ответы, пропуски, лишние выделения и ошибки границ.

Автор bbox исключается через `unavailable_for` страницы; для страницы
исключаются авторы всех включённых ответов. При экспорте повторно проверяется
независимость авторов и ревьюеров. Два review должны принадлежать разным людям.

Два положительных review допускают ответ к финальной проверке командой.
Любое замечание или сомнение ведёт на разбор, повторную разметку либо исправление.
Конкретно найденный пропуск нельзя автоматически отменять большинством голосов.
Исправленная версия проходит новую независимую проверку. Все версии сохраняются.

## Финальная проверка и golden set

План предусматривает просмотр всех 400 фотографий участниками команды,
а исправлений — другим участником. Эта работа команды не оплачивается
из платформенного бюджета; её нужно учитывать как отдельные трудозатраты.
Приоритет внимания: пустые ответы, похожие насекомые, мелкие объекты,
перекрытия, расхождения с предварительными метками и ответы исполнителей
с проблемами контроля качества.

Модельная предразметка по умолчанию не используется, чтобы не переносить
ошибки сравниваемых моделей в эталон. Если модель всё же применяется для
исправления, это явно фиксируется и не заменяет независимую человеческую проверку.

Golden set содержит каждый ID набора ровно один раз: подтверждённые рамки
или подтверждённое отсутствие бабочек. Неразобранные случаи и технические
ошибки блокируют финальный экспорт. Исходные ответы, review, исправления,
краткие объяснения и авторство решений сохраняются отдельно от итогового JSONL.

## Бюджет

Расчётное допущение — комиссия **40%**, как в примере ДЗ-2. Это не подтверждение
тарифа текущего аккаунта: перед запуском проверяем фактическую комиссию
и пересчитываем план. Цены и экзаменационные пороги — начальные параметры
пилота, а не гарантия качества или скорости набора исполнителей.

| Статья | Расчёт выплат | Выплаты | С комиссией 40% |
| --- | --- | ---: | ---: |
| Основной bbox, включая пилот и скрытые контроли | 100 страниц × 2,50 ₽ | 250 ₽ | 350 ₽ |
| Экзамен bbox | до 20 попыток × 1 ₽ | 20 ₽ | 28 ₽ |
| Два review каждого ответа | 80 страниц × 2 × 0,75 ₽ | 120 ₽ | 168 ₽ |
| Экзамен review | до 20 попыток × 1 ₽ | 20 ₽ | 28 ₽ |
| Повторный bbox до 60 изображений | 15 страниц × 2,50 ₽ | 37,50 ₽ | 52,50 ₽ |
| Два review повторных ответов | 12 страниц × 2 × 0,75 ₽ | 18 ₽ | 25,20 ₽ |
| Всего с выделенными повторными заданиями | | 465,50 ₽ | 651,70 ₽ |
| Дополнительный резерв review | | | 32,20 ₽ |
| Общий нераспределённый резерв | | | 166,10 ₽ |
| Общий лимит | | | 850 ₽ |

На review предусмотрено 221,20 ₽ плановых расходов и 32,20 ₽ дополнительного
резерва — всего **253,40 ₽**. Дополнительный резерв получен снижением цены
bbox с 2,70 до 2,50 ₽ и предназначен для повышения ставки review или
дополнительных проверок. Из оставшихся после плановых расходов 198,30 ₽
свободными остаются 166,10 ₽; остальные 32,20 ₽ закреплены за review.

Контроли входят в оплачиваемые страницы. Практика не оплачивается.
Повторные попытки, дополнительные экзамены, переделки после изменения
инструкции и повышение ставок требуют расхода резерва и нового расчёта.

Сравнение объёмов при одинаковых ставках, лимитах экзаменов и повторного bbox:

| Фотографий | План с комиссией | Свободный резерв после выделения 32,20 ₽ для review |
| --- | ---: | ---: |
| 400 | 651,70 ₽ | 166,10 ₽ |
| 450 | 718,20 ₽ | 99,60 ₽ |
| 503 | 786,80 ₽ | 31 ₽ |

Расходы считаются по страницам с округлением вверх для каждой партии. Перед каждой новой партией
учитываются оплаченные ответы, стоимость уже выданных заданий и максимальная стоимость
новой выдачи. Платные экзамены и повторные задания имеют конечные лимиты.
Автоматическое перевыставление отклонённых ответов не должно обходить бюджет.
Остановка по таймеру не является единственной защитой.

## Воспроизводимость и развитие

Код bbox находится в `crowd/bbox/`. Review — отдельная задача.
Общий пакет появится только при необходимости повторного использования кода.

Сохраняются версии manifest и инструкций, настройки, ID проектов и пулов,
операции API, исходные ответы, оценки контроля и расходы.
