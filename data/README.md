## Сбор данных

- собраны 600 кандидатов iNaturalist с CC0, после проверки оставлены 593
- получилось 462 фотографии бабочек (включая мотыльков), 73 похожих объекта (незрелые особи, коконы, другие насекомые), 58 unrelated (другие животные, растения)
- candidates.csv — исходный список фотографий, selection.csv — после ручной обработки, manifest.csv — итоговый список

Скачать фотографии можно следующим образом:

```bash
python -m pip install -r data/requirements.txt
python data/download.py --input data/manifest.csv
```

Для воспроизводимости сохранены исходные ссылки, решения отбора и параметры сбора
